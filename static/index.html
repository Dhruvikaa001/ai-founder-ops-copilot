🏗 Production architecture note
In a production build: this would be a Next.js 14 frontend with TypeScript + shadcn/ui, backed by a FastAPI microservice with Pandas pipelines, a PostgreSQL database for multi-client data isolation, and a Celery + Redis task queue for async report generation. PDF extraction would use a dedicated OCR service (AWS Textract or Azure Form Recognizer). The AI layer would be provider-agnostic (Claude or GPT-4o swappable via environment config).
